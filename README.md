# FEAT
This repository contains Jupyter Notebooks and csv files that support the following publication:

Seymour, Kyle, Maximilian Held, Gil Georges, and Konstantinos Boulouchos. "Fuel Estimation in Air Transportation: Modeling global fuel consumption for commercial aviation." *Transportation Research Part D: Transport and Environment* 88 (2020): 102528.
https://doi.org/10.1016/j.trd.2020.102528.
